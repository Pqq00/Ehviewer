feat(cache): show per-layer usage and clear caches by scope

Settings used to expose one "image cache" row that wiped every layer at
once. Now the storage section lists the four real layers - HTTP responses,
parsed list/detail models, page lists and reader images - with their own
size and their own confirm dialog, plus the Coil loader row.

- core HttpCacheBridge.sizeBytes (SQLite SUM(LENGTH(body)) on Android)
- GalleryCacheStore.usageBytes (database file size on Android)
- CacheManager/CacheScope as the single place that reports usage and
  clears one scope, so logins and site switches keep their own bridges
- parsed-model keys now carry a schema version and the signed-in state,
  and PAGE/DETAIL TTLs follow the HTTP cache (1h/6h) instead of 7 days
